# Aromas Art — GitHub Pages

Sitio estático de catálogo de perfumes, preparado para publicarse desde GitHub Pages.

## Publicación
1. Crea un repositorio en GitHub, por ejemplo `aromasart`.
2. Sube **todos** los archivos y carpetas de este paquete; `index.html` debe quedar en la raíz.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/ (root)`, y guarda.
5. Espera a que termine el despliegue. El enlace tendrá la forma `https://TU-USUARIO.github.io/aromasart/`.

## Importante
- Este paquete es la versión estática del sitio. El proyecto original incluye una app React/servidor incompleta: su ruta principal importa `src/components/aromas-app`, pero ese componente no está incluido en el ZIP original.
- Las cuentas, sesiones y carrito de esta maqueta funcionan en el navegador mediante `localStorage`; **no son autenticación segura ni una tienda con backend**. No uses contraseñas reales ni datos sensibles. Para vender de forma real, conecta autenticación y pedidos a un backend seguro.
- Verifica el número de WhatsApp y los precios antes de compartir el enlace públicamente.
